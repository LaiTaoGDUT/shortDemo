竞价商城系统API

概述

本API用于竞价商城系统的开发

当前版本：bata 0.1

顾客相关的接口

顾客是一个该商城系统最核心的组成部分。这里将会提供包括注册、登录等相关接口。

注册register

用于注册的接口。注册成功后，系统自动登陆该用户并记住登陆状态。

接口地址

/registerServlet

请求参数

{
userId:'18933247746',//字符串，用户ID，用来登陆系统
userName：'admin',//字符串，用户昵称
userPassword:'123123'//字符串，密码
}

返回参数

调用成功，则返回

{
"result":"success",//字符串，表示成功状态，下同
"userId":"18933247746" //字符串，服务器会返回顾客的id
}

调用失败，则返回

{
"result":"failed",//字符串，表示失败状态，下同
"reason":"服务器错误"//字符串，提示信息，如未设置密码
}

登录login：post

用于登录的接口。所有接口中，有相当一部分接口都是需要用户登录之后才可以正常使用的。当用户登录以后，服务器会记住用户的登录状态。

登陆后，如果长时间没有进行操作，服务器会认为用户已经下线。你可以通过下线接口（logout）来主动下线。

接口地址

/loginServlet

请求参数

{
userId:'18933247746',//字符串，顾客ID
userPassword:'123123'//字符串，密码
}

返回参数

调用成功，则返回

{
"result":"success",//字符串，表示成功状态，下同
"userName":'LaiTao'//字符串，服务器会返回用户的id
}

调用失败，则返回

{
"result":"failed",//字符串，表示失败状态，下同
"reason":"服务器错误"//字符串，提示信息，如未设置密码
}

下线，登出logout：post

用于下线的接口。

接口地址

/logoutServlet

请求参数

无

返回参数

只返回一句

{
"result":"success"
}

失败则返回

{
"result":"failed",
"reason":"服务器错误"
}

竞价商品加价addAuction：post

对某个商品的竞价活动进行加价，该接口是供已参与竞价的商品使用，对未参与竞价的商品，应使用参与商品竞价接口

接口地址

/addAuctionServlet

请求参数

{
productID:'123123'//字符串，商品ID
addMoney:'100.00'//字符串，此次加价的金额
}

返回参数

调用成功，则返回当前参与的商品信息

{
"result":"success",
"acquire":true//布尔值，是否能拍得
}

失败则返回

{
"result":"failed",
"reason":"服务器错误"
}

商家相关的接口

发布商品releaseProductServlet：post

接口地址

<项目地址>/releaseProductServlet

请求参数

{
productName:'冰箱'//字符串，商品名
productNum:'100'//字符串，商品数量
productImage:'asdjoaisdo'//字符串，商品图片的base64格式
beginTime:'2019-11-04 12:00'//字符串，规定格式的时间
endTime:'2019-11-04 12:00'//字符串，规定格式的时间
startPrice:'100'//字符串，商品起拍价
maxPrice:'100'//字符串，商品最高价
productDeposit:'100'//字符串，商品的定金
productExplain:'这是简介'//字符串，商品简介
}

返回参数

调用成功，则返回

{
"result":"success"//字符串，表示成功状态，下同
}

调用失败，则返回

{
"result":"failed",//字符串，表示失败状态，下同
"reason":"unlog"//字符串，提示信息，如未登录
}
